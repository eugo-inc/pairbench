# pairbench reference

The reference pages list every command, flag, config key, exit code, text code, results field
and public Python name, each with its own anchor.

- [Commands](commands.md): every command and flag.
- [Config](config.md): every key of the config file, with its default.
- [Environment variables](environment.md): every variable pairbench reads or sets, and who
  defines it.
- [Exit codes](exit-codes.md): the exit codes and every text code.
- [Results schema](results-schema.md): the files of a run, `results.json`, the figures and
  `diagnostics.json`.
- [Text input format](text-format.md): rows written by hand or by another program.
- [Python API](python-api.md): the functions, sides, rules and statistics primitives.
- [Plug-in API](plugin-api.md): adding sides, drivers, readers, checks, rules, reporters and
  launchers.
- [Tool server](tool-server.md): `pairbench mcp` for AI agents.
